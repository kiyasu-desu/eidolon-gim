# Eidolon-GIM

[中文说明](README.md) · [日本語](README.ja.md)

A local-first, unofficial Gakuen Idolmaster conversation app, currently focused on Tsukimura Temari. Text, Japanese replies with Chinese subtitles, personal memory and WebRTC calls build on the upstream Eidolon-SC foundation.

Model and story packs are optional and distributed separately from source. See [configuration](docs/configuration.en.md), [local resource packs](docs/local-resource-packs.md), [story import](docs/gim-story-import.md), [model pipeline](docs/stand3d-pipeline.md) and [deployment](docs/deploy-gim.md).

SC characters, world data, media, import/sync adapters and the old Spine renderer have been removed. Generic user-data and conversation features remain. No raw game assets, story texts or private databases are provided.

Source is AGPL-3.0-or-later. See [LICENSING](LICENSING.md) for upstream and third-party attribution. This is a fan project, unaffiliated with the rights holders; character responses are generated by AI.

Current delivery and the planned next stage: [project roadmap](docs/project-roadmap.md) (Chinese). The next stage is planned only; implementation has not started.
