# Eidolon-GIM

[中文说明](README.md) · [English](README.en.md)

学園アイドルマスターの非公式会話アプリです。現在は月村手毬のみを対象に、日本語の返答と中国語字幕、個人メモリー、WebRTC 通話を提供します。基盤は上流の Eidolon-SC を継承しています。

モデルとシナリオは任意のローカルパックとして別途用意します。[設定](docs/configuration.ja.md)、[パック](docs/local-resource-packs.md)、[シナリオ取り込み](docs/gim-story-import.md)、[モデル処理](docs/stand3d-pipeline.md)、[デプロイ](docs/deploy-gim.md)を参照してください。

旧作品のキャラクター・世界データ・画像・同期処理・Spine 描画は削除しました。汎用の会話・アカウント・メモリー機能は維持しています。ゲーム素材、シナリオ本文、個人データベースは配布しません。

AGPL-3.0-or-later。[ライセンスと出典](LICENSING.md)を参照してください。権利者とは無関係のファン作品で、返答は AI が生成します。
