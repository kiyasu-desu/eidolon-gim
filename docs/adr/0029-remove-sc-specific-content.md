# 移除旧作品内容，保留通用对话能力

2026-10-29。按用户要求，当前工作树只保留学马内容。移除旧角色、人设、事实、头像、背景、世界文件、剧情及立绘镜像适配器、同步命令、cron 脚本、Spine 渲染器和旧落地页演示。通用的账户、聊天、记忆、检索、语音、后台、世界资料加载及备份继续使用；作品相关提示词改为学马。

这取代 ADR-0004、0009、0011 的当前适用范围，以及 ADR-0008、0016 中旧作品来源和演示的部分。历史 ADR 保留原文并注明状态，供理解继承代码使用；上游 AGPL 及第三方署名不删除。通用测试改用原创虚构人物和资料，不继续携带旧作品角色及真实剧情样本。

只清理当前源码与维护文档，不改写 Git 历史，不修改本地用户数据库，不推送或部署。移出的文件有私有本地回退副本，后续正式发布若要求清理历史，需要另行决定发布历史方案。

角色配置与接口中的旧作品专用命名也已移除：备用头像统一为 `alternate_avatar` / `alternate_avatar_url`，显示顺序为 `display_order`，衣装仅接受 `stand_3d/<slug>`。前后端需配套更新；旧作品的配置不再兼容。当前手毬配置不使用这些旧字段，用户数据库不需要改写。移除的落地页媒体接口不再提供。

旧作品的剧情与判断校准集已替换为原创的学马入门样例。这些样例不是经过真实服务校准的阈值结果；部署者仍需用自己的许可资料复验检索质量。
