# 项目阶段与下一阶段目标

更新：2026-10-29。当前默认月村手毬单角色，支持本机运行及OAuth白名单的私密部署。模型、剧情和用户数据独立于公开源码。

## 一期已交付

- 文字对话、日语回复／中文字幕、记录恢复和用户记忆。
- 剧情准入审计、条件分支隔离、独立剧情库与向量检索；已有有限真实文字／语音用例验收。
- Fish角色音色、远程识别、WebRTC通话及异常恢复；Windows中性语音限本机原生运行。
- 当前衣装的网页3D模型、原动作烘焙、制作待机／讲话保持、三组动作、局部物理与材质校准。
- 模型与剧情独立启停、缺资源回退、四组合及干净源码启动验收。
- 旧作品专属内容移除、源码发布门禁、双平台模型流水线CI及Linux私密部署。
- 姓名纠音、有依据的爱称、长回复动作轮换及小幅聆听反应。

具体实现边界见[资源包](local-resource-packs.md)、[模型流水线](stand3d-pipeline.md)、[部署](deploy-gim.md)和[发布](releasing.md)。测试通过只覆盖记录的用例，不保证所有回复、音色重音或几何场景都正确。

## 下一阶段：稳定运行与体验质量

状态：**待启动，只明确目标，本次不实施**。下一阶段以现有单角色交付为基线，按以下顺序收口；每项实施前再确定规格和可复现验收。

| 优先级 | 目标 | 启动后的完成标准 |
| --- | --- | --- |
| P1 | 备份与恢复可验证 | 确认备份任务、频率、保留期和保存位置；用隔离副本验证账户／对话／记忆及独立剧情库恢复；保留原库与应用回退记录 |
| P1 | 明确依赖审计状态 | 重新取得当前锁文件及生产镜像的审计证据，区分工具链与运行依赖；逐项修复或记录可核实的处置依据，跑受影响检查和CI |
| P2 | 跟进真实使用中的语音和动作问题 | 先记录具体输入、设备及期望；用人试听评价读音／爱称自然度，用真实长短回复检查动作重复、打断和暂停连续性；有复现再修改 |
| P2 | 运行问题可追踪 | 确认已有健康、服务探测、错误记录和额度观察方式；只对实际缺口制定变更，明确何时需要人工处理 |

当前有逐次部署备份和既有验收证据；周期备份是否覆盖全部资源与恢复是否可重复，仍需专项核对。2026-10-29部署构建记录过9项依赖审计告警（6 high、2 moderate、1 low）；这不是本轮新扫描结果，也不能据旧的“0漏洞”说明当前状态。

## 后续候选

精确音素口型、低性能设备专项优化、原物理／Avatar／渲染精确复刻、多角色、多服装、日语界面及好感度／礼物均不作为下一阶段默认任务。需要时单独确定目标、资源条件和验收预算。

本文件定义目标，不授权自动实施、升级依赖、建立定时任务或部署。当前具体提交、镜像摘要、私有配置和验收报告由各部署环境维护；核对方法见[发布说明](releasing.md)。
